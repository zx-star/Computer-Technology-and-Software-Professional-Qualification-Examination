# 项目介绍

本项目是一个基于 VitePress 构建的**软考高级系统架构设计师**备考知识库，按教材章节组织（第一章 ~ 第十八章），覆盖笔试三科内容。后续章节会随着学习进度持续补充。

## 用途

- **知识沉淀**：将讨论中理解的知识点结构化记录，形成持续积累的个人知识库。
- **可视化浏览**：通过 VitePress 提供的侧边栏导航、全文搜索、目录大纲等功能，快速定位和复习。
- **难点追踪**：对反复讨论、容易混淆的概念单独整理，方便考前集中回顾。

## 考试说明

系统架构设计师属于全国计算机技术与软件专业技术资格考试（简称"软考"）中的**高级**资格，每年举行两次（通常在 5 月和 11 月）。

考试分为三科，均在同一天完成，三科须**同时达到 45 分**方为通过，单科成绩不保留：

| 科目 | 题型 | 时长 | 满分 | 合格线 |
| ---- | ---- | ---- | ---- | ------ |
| 综合知识 | 选择题（75 道） | 150 分钟 | 75 | 45 |
| 案例分析 | 问答题（5 选 3） | 90 分钟 | 75 | 45 |
| 论文 | 写作题（4 选 1） | 120 分钟 | 75 | 45 |

## 笔记与课件原文的区别

本项目有两套平行内容，按教材章节一一对应，但定位不同：

| | 笔记（`/notes/`） | 课件原文（`/source/`） |
| ---- | ---- | ---- |
| 定位 | 精简备考笔记 | 课件原始内容，无精简 |
| 内容 | 浓缩为关键词和一句话要点，可加个人感悟 | 完整保留课件原文，不做删减或改写 |
| 用途 | 考前快速复习、扫盲 | 对照原文查漏补缺，确保不丢细节 |
| 进度 | 按需逐章填充 | 对照课件截图录入原文 |

两套内容页面顶部均设有互相跳转的链接，可在精简版与原文之间快速切换。

## 写作约定（供 AI 协作参考）

- **重点文字**：课件中需要强调的关键点，在 Markdown 中使用行内代码语法 `` `…` ``。普通文字直接使用 Markdown，不加包裹。
- **目录骨架**：每章文件开头为 `# 第X章 标题`，然后是 `## 知识点目录`（编号列表），再按 `## N 小节名` / `### N.M 子节名` 展开正文。未填充的小节写 `待补充。`
- **章节目录**：`docs/notes/chapter-NN/`（笔记）与 `docs/source/chapter-NN/`（原文），章节号两位补零，页面文件为 `index.md`，侧边栏链接为 `/notes/chapter-NN/` 或 `/source/chapter-NN/`。
- **图片**：存放于对应章节目录下，用相对路径引用（如 `./software-process-model.png`）。
