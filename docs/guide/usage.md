# 使用说明

## 本地运行

在项目根目录执行 `pnpm install` 安装依赖，然后 `pnpm dev` 启动开发服务器。

启动后浏览器访问 `http://localhost:5173` 即可查看笔记。

## 常用命令

- pnpm dev 启动本地开发服务器，支持热更新
- pnpm build 构建静态站点，输出到 docs/.vitepress/dist
- pnpm preview 本地预览构建产物

## 功能特性

- 侧边栏导航：按知识领域分类，支持折叠展开
- 全文搜索：点击顶部搜索框或使用快捷键，输入关键词检索全部笔记
- 目录大纲：右侧自动生成当前页面的标题大纲，点击快速跳转
- 暗色模式：右上角切换浅色深色主题
- 最后更新：每页底部显示最近修改时间

## 写笔记的方式

笔记以 Markdown 编写，存放在 docs/notes/ 目录下对应的知识领域文件夹中。每个 md 文件即一个笔记页面，VitePress 会自动将其渲染为网页。
